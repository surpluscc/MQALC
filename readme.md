# Usage Instructions

1. Run `generate.py` in the `generate and Iteration` folder to start generating code.

2. Run `run_full_evaluation.py` in the `pass@k` folder to evaluate code correctness and obtain functionally correct code.

3. Evaluate the code that passes the correctness tests using the following metrics: ET, MU, CoC, and MI.

   ## ET and MU

   1). Add the code to `generate_code_passed.json`.
   2). Run `test_performance.py`.
   3). Run `generate_statistics_report.py`.
   4). Run `generate_report.py`.

   After completing these steps, all ET and MU evaluation reports will be generated.

   ## MI

   1). Add the code to `generate_code_passed.json`.
   2). Run `batch_analyze.py`.

   The MI evaluation report will then be generated.

   ## CoC

   1). Install SonarQube.
   2). Modify the `generate_code_passed` file and update it with the code to be evaluated.
   3). Run `get_cognitive_complexity_auto.py`.
   4). Run `match_and_analyze.py`.
   5). Run `cognitive_complexity_report.py`.

   The CoC evaluation report will then be generated.

4. Open `topsis.py` in the `MQALC Score` folder to calculate the final scores and rankings.

5. Run `Iteration.py` to obtain the optimized code. Then repeat the steps above to calculate the metric values for the optimized code.

6. Run `topsis_compare.py` to obtain the comparison results before and after optimization.

Some files contain example templates. Please modify them according to your specific requirements before use.

## Note

Because `LCQBench-555c` is constructed as the intersection of functionally correct code generated by different models, its contents may vary under different experimental settings. Therefore, a fixed version of the `LCQBench-555c` dataset cannot be provided.

Users can construct their own `LCQBench-555c` dataset based on `LCQBench-555`.
